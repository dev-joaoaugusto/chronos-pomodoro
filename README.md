Chronos Pomodoro

O **Chronos Pomodoro** é uma aplicação web de gerenciamento de tempo baseada na metodologia Pomodoro, desenvolvida como projeto prático do **Curso de JavaScript e TypeScript** ministrado pelo professor **Luiz Otávio Miranda**.

O projeto tem como objetivo consolidar na prática os conceitos fundamentais do ecossistema moderno do React 19, TypeScript e ferramentas de build.
